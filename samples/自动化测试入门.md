# 自动化测试学习包
本资料是 Learnloop 自有练习说明，不替代上游官方文档。
## 断言
断言用于比较实际结果与预期结果。pytest 支持 Python assert；例如 assert discount(100, 0.2) == 80。
不要只验证程序没有抛异常。边界值和异常行为也需要被测试。
## Fixture
pytest.fixture 定义测试所需资源。默认 function 作用域意味着每个测试获得一次独立资源。
使用 yield 可以在交出资源之后执行清理。共享可变状态时应特别检查作用域，否则测试可能互相影响。
## 定位器
Playwright get_by_role 允许按角色和可访问名称定位元素，例如 page.get_by_role('button', name='提交订单')。
定位器需要唯一匹配，不能认为角色定位器在所有页面上都自动唯一。应检查可访问名称与页面语义。
## 等待与断言
Playwright 的 expect(locator).to_have_text(...) 是带重试的断言，适合等待可观察的状态变化。
固定 time.sleep 会让测试变慢或在环境较慢时不稳定，应优先等待具体条件。
## Page Object
页面对象封装页面行为，让测试表达用户意图。不要把所有断言和业务逻辑藏入一个巨大的公共类。
CheckoutPage 可以封装打开结算页和点击提交，测试仍显式检查提交前后的状态。
## 项目目标
实现两个测试：初始状态为等待提交；点击提交订单后状态为订单已确认。
使用角色定位器、重试断言和 CheckoutPage，解释这些选择的理由。
