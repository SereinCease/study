秋夜素材与受光合成说明

这是第一阶段记录。人物微动、纸面星轨与番茄钟已在第二阶段加入，详见 动效与专注模式说明。

本轮交付一套重新绘制的秋夜书斋、独立人物与书卷素材，以及可调灯光的 Three.js 样板。当前是固定机位 2.5D 验证，不是完整三维房间或已绑定骨骼的角色。

渲染链路

  1. 使用本地 Three.js 0.186.1、正交相机与单个全屏平面，一次 draw call 合成背景、人物、法线或原稿；不依赖 CDN。
  2. 颜色贴图使用 sRGB 输入，法线使用 NoColorSpace。漫反射在线性空间计算，最后由 Three.js 统一转为 sRGB 显示。
  3. 人物和法线使用同一坐标变换：原图像素 x = 449 + 0.63 × 素材 x；原图像素 y = 106 + 0.63 × 素材 y。透明度在 shader 内平滑收敛，去掉极低透明噪点。
  4. 冷月光方向可调；暖光从室内左前方照入。法线点积控制受光面，透明边缘梯度与光向点积控制局部轮廓光。没有对整个人物套统一发光描边。
  5. 坐垫上的软椭圆阴影在人物之后合成；裙摆在透视桌沿处遮挡。两者都是固定机位代理，不等同于真实几何投影。
  6. 人物原画已经含明暗，因此灯光采用克制的插画再受光，不能精确去除原画烘焙的月光或烛光。单光预设关闭的是新增动态光源。

查看方式

选择“双光受光”后调节月光、烛光、轮廓光、接触阴影；“原始颜色”关闭新增光影；“法线检查”观察方向数据；“重制全景稿”查看原始场景参考。可切换全景、人物与书卷、坐垫接触三个裁切观察区域。滑杆支持方向键。

性能与回退

  • 设备像素比最多 1.5；默认按需渲染，不保持空转动画循环。
  • 烛光变化为主动开启。离开视口、页面隐藏或系统减少动态效果时停止循环；恢复时按当前设置继续。
  • 卸载释放几何体、材质、纹理、观察器与渲染器；页面从 bfcache 恢复时重新初始化。
  • 纹理加载失败、WebGL 不可用或上下文丢失时保留原始全景图，禁用调光控件并提供重新加载。
  • 本轮四张输入 PNG 总计约 7.5 MB，四张 RGBA GPU 纹理约 24 MiB（不含帧缓冲）。这是本地美术样板，尚未实施发布级纹理压缩或移动设备性能基准；不声称已经稳定达到 60 FPS。

下一阶段接口

当前衣袖与书卷是一个整体透明层。要做呼吸、翻书、抬手，应先制作可见区域补全与身体/手臂/书页分层，再让颜色与法线同步形变。自由运镜需要真实深度层或三维角色；不能把本样板平面直接大角度旋转。天气、案头星轨动画、器物拾取和专注运镜属于后续里程碑。

启动与文件

在项目目录执行 python3 -m http.server 4174 --bind 127.0.0.1 --directory design/ink-starlight，访问 /autumn-lighting/。已有服务运行时无需再次启动。
